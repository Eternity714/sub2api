# 充值页 CDK 入口和订阅余额支付

用户需要在“充值/订阅”页面底部购买 CDK，并用已有账户余额直接购买或续费订阅。

## 验收标准

- AC-031.1：充值和订阅页面的公共底部显示“在线CDK购买充值”；无外部支付渠道时也可见。点击在新页签打开 https://catfk.com/shop/BK9HYWAR，原页签保留。
- AC-031.2：支付系统及订阅功能启用时提供订阅余额支付，无需配置外部支付渠道。关闭相关功能则不允许新增购买；“禁止余额充值”不等同于禁止余额消费。
- AC-031.3：余额付款只扣服务器确认的套餐 USD 标价，按 USD 两位小数处理，不使用外部支付汇率、渠道手续费、充值倍率或充值赠金。用户不能指定扣款价格；确认页报价与当前服务端价格不一致时，拒绝扣款并更新报价，要求重新确认。
- AC-031.4：订单完成、足额扣款、订阅开通/续期和账务审计同时成功；任何提交前失败均完整回滚，不能残留扣款或部分订阅。
- AC-031.5：余额不足不扣款、不发放；余额恰好够用时可归零，保留未花费的细小额度。并发购买不能透支或覆盖其它扣款。
- AC-031.6：同一购买请求并发、重试或响应丢失后返回原完成订单，只扣款和发放一次；同一请求标识改用其它套餐应拒绝。已完成购买的回放不受之后停售或改价影响。
- AC-031.7：身份来自已登录用户；用户不能用他人用户 ID、订单或请求标识消费或读取他人结果。
- AC-031.8：购买及续费沿用现有订阅规则；并发续期天数累计，不覆盖已有期限。停售、无效套餐、无效分组和停用账户不产生新增扣款。
- AC-031.9：余额消费不再次发放充值返佣，不计入外部现金收款，不调用外部支付网关。外部回调和补发流程不能对余额订单再次发放；本功能不提供外部网关退款。
- AC-031.10：用户明确确认余额扣款，能看到扣款与剩余余额；不足时提示并阻止新购买。提交中防重复并禁止切换购买；结果不明确时保留账户隔离的同一请求标识及确认报价，先核对该购买结果，再允许取消或切换。刷新、余额已扣至零、套餐停售及旧版服务返回通用错误时，也能恢复并核对原购买。
- AC-031.11：成功后保留已完成结果并刷新余额与订阅；刷新失败不能把完成订单变成付款失败。旧后端缺少余额能力字段时不显示余额方式；原外部付款保持可用。
- AC-031.12：余额与订阅缓存在事务提交后失效；缓存失效失败不造成重复扣款，完成订单重放可以修复缓存。

## 范围

增加一个 CDK 外链和一种订阅支付方式。继续使用既有套餐、余额、订单及订阅记录；不增加优惠券、混合付款、余额提现或余额订单退款功能。
