# F03/F06 持久任务、额度预留与结果交付

统一媒体请求先完成F01/F02校验及参数候选匹配。合法请求创建本地queued任务并冻结余额，同时将API Key总额和窗口额度的未结媒体任务占用纳入并发准入。账号提交前绑定，多用户共享账号总/日/周额度。无账号仍完成任务创建，后台统一结束并释放。

后台处理已受理任务固定原账号轮询。提交前保存意图；提交受理不明或恢复时发现无上游ID的提交意图，禁止重提。后台有限重试、到期终结；所有执行单元结束后仅交付成功转存S3的URL，并收成功部分费用、释放差额。GET必须同用户、同Key、同媒体路径，且只读。completed只表示处理结束。

验收：并发额度不透支；恢复不重复提交/扣费；S3部分成功可恢复；无账号和受理不明最终释放；查询隔离；公开三状态及0/50/100；账号消耗不进入用户平台额度。
