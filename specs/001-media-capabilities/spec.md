# Feature Specification: F01 统一媒体协议与模型能力

**Feature Branch**: `codex/unified-media-generation`
**Created**: 2026-10-15
**Status**: Implemented; final verification pending
**Input**: 已确认媒体PRD及F01切片；管理员维护能力配置，下游按路径和模型获得严格、可解释的参数校验。

来源：[媒体PRD](../unified-media-generation/prd.md)、[能力基线](../unified-media-generation/capability-matrix.md)、[切片](../unified-media-generation/feature-breakdown.md)。

## User Scenarios & Testing

### User Story 1 - 管理员配置模型能力 (Priority: P1)

管理员选择图片或视频基础模板，配置公开模型、字段、默认值、输入模式及约束，保存后重新读取。相同公开模型可以分别有图片、视频记录。

**Why this priority**: 配置是严格校验与后续路由的基础，不允许靠未知字段透传扩大能力。
**Independent Test**: 通过管理界面完成模板→编辑→保存→读取，能力记录按模型和媒体类型隔离。

**Acceptance Scenarios**:
1. Given 管理员选择图片模板，When 修改字段和模式并保存，Then 读取到独立配置及版本，模板升级不自动覆盖它。
2. Given 同一模型已有图片记录，When 新建视频记录，Then 可同时存在；重复创建同媒体记录返回冲突。
3. Given 两个管理员读取同版本，When 第一人保存后第二人按旧版本保存，Then 拒绝覆盖并保留其编辑内容。
4. Given 普通用户，When 尝试管理能力配置，Then 服务端拒绝访问。

### User Story 2 - 调用者得到明确参数校验 (Priority: P1)

调用者只使用统一字段。模型与输入模式决定字段是否支持、是否必填和组合是否合法；不合法请求不会产生任务或费用。

**Why this priority**: 防止传错媒体类型、默默丢字段或降规格。
**Independent Test**: 不调用上游的校验预览可验证合法、非法及候选匹配场景。

**Acceptance Scenarios**:
1. Given 图片能力，When 请求带视频顶层duration，Then 返回字段错误；未知顶层与嵌套metadata字段同样拒绝。
2. Given 模型只支持视频，When 通过图片语义校验，Then 拒绝；模型同名双媒体时各自使用正确规则。
3. Given 素材驱动模式允许省略prompt，When 素材合法且提示词未传，Then 通过；要求提示词的模式缺失时拒绝。
4. Given 模型有明确比例和分辨率对应表，When 请求匹配组合，Then 固定实际输出规格；未知组合拒绝，不猜测像素，不增加output_size。
5. Given 单次一张但允许拆分的候选且整项上限允许3张，When 请求n=3，Then 保留该候选并标识需拆分；不绕过整项数量上限或拆散语义关联组图。
6. Given Seedream5Pro普通生成已配置，When 请求图层分解，Then 拒绝该模式，普通生成仍可用。

### User Story 3 - 配置变更不改变已接受请求 (Priority: P1)

系统为通过校验的请求提供规则版本、规范化参数与实际规格依据，供后续任务创建固定保存。

**Why this priority**: 管理员改配置不能让在途任务重启后改参数或改价。
**Independent Test**: 使用同一输入生成快照，修改数据库规则后快照内容仍不变。

**Acceptance Scenarios**:
1. Given 校验成功，When 构建能力快照，Then 包含配置标识、版本、完整规则及摘要；后改配置不能修改此快照。
2. Given 参数已显式提供，When 填补缺省值和匹配候选，Then 不覆盖显式值，不补虚构prompt，不改请求语义。

### Edge Cases

- 重复JSON键（含嵌套）、大小写伪装字段、多个JSON值、null根对象、错误数字类型、深度或体积超限。
- 模式匹配零个或多个、默认值不符合字段约束、配置引用不存在字段、非法范围、未知规则或任意表达式。
- 没有有效schema与存储暂不可用不能混为参数错误；“参数支持但没有账号”留给F02/F03创建异步任务。
- 管理预览不生成任务、不冻结资金、不发上游请求；未公开新的下游能力查询接口。

## Requirements

### Functional Requirements

- **FR-001**: 管理员可新建、读取、更新、禁用、删除按公开模型和媒体类型区分的能力记录；所有写入经过完整校验及并发版本检查。
- **FR-002**: 提供版本化图片、视频基础模板；应用是独立副本，不自动启用未知型号或覆盖现有配置。
- **FR-003**: 图片顶层只允许model/prompt/size/n/image_urls/metadata；视频只允许model/prompt/duration/aspect_ratio/image_urls/metadata。model固定必填；prompt按模型与模式决定。
- **FR-004**: 严格校验嵌套字段、类型、必填、可空、枚举、范围、长度、数量、默认值和组合约束；指出字段路径及原因；不静默丢字段或降规格。
- **FR-005**: 每次请求由路径媒体类型与模型标识选择能力；未知或无效能力在任务、额度和上游动作之前拒绝。
- **FR-006**: 图片size是比例，metadata.resolution是模型分辨率档位；存在映射要求时只接受有依据的组合，不新增metadata.output_size。没有像素映射需求的模型仍可按已声明比例字段校验。
- **FR-007**: 视频duration单位为秒；具体类型、取值、省略规则与默认值按模型及模式约束，不能强加通用默认或自动时长收费规则。
- **FR-008**: 输出规范化参数、显式提供字段、匹配模式与不可变能力快照；候选匹配不得改变已接受语义，须区分整项结果上限和上游单次数量。
- **FR-009**: Seedream5Pro图层分解模式拒绝；待定的混合媒体辅助输出和供应商绑定资源不因metadata可扩展而自动放行。
- **FR-010**: 管理界面提供可操作的基本字段及限制表单，模式和复杂嵌套可在高级编辑中维护；保存错误保留草稿，预览只执行校验。
- **FR-011**: 固定统一响应契约：queued/in_progress/completed对应0/50/100；completed只代表结束；结果为type与URL字符串数组，error字符串，时间为Unix秒，终态才有completed_at，有成功结果才有expires_at。
- **FR-012**: 本切片不挂载真实生成链路，不实现账号调度、任务资金事务、S3或正式扣费，不停用旧入口；上述能力由F02—F08贯通后统一开放。

### Key Entities

- **模型能力记录**：模型、媒体类型、启用状态、规则版本、模板来源及规则内容。
- **字段与模式规则**：允许参数、缺省值、条件必填和组合限制。
- **规范化请求与快照**：通过校验的请求、匹配模式、规则版本和输出规格。
- **候选能力匹配结果**：是否支持原请求、是否需要拆分及具体错误。

## Success Criteria

### Measurable Outcomes

- **SC-001**: F01主归属AC-014～020、026、027全部具备可运行验证场景。
- **SC-002**: 所有已定义的非法输入场景均被拒绝，且产生的媒体任务、资金变动及上游生成调用均为0。
- **SC-003**: 管理员能完成模板复制、基本字段编辑、保存及回读；同名双媒体不会覆盖，旧版本更新不会覆盖新版本。
- **SC-004**: 所有通过的规范化请求均保留显式值和可追溯规则快照，候选匹配不发生静默参数降级。

## Assumptions

- 沿用现有管理员身份与管理页面规范；基础模板是配置起点，不代表整个模型目录默认可用。
- 多平台真实候选、完整请求接入、任务资金生命周期在后续切片实现；本期验证不需要付费生成。
- 大小、深度等工程边界在plan定义；辅助输出、绑定资源和自动时长收费的未决项不阻塞公共校验器。
