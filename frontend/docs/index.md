## 本站接入地址

> **根据协议选择地址**
>
> API 服务地址是 `https://www.gkotta.bid`。OpenAI 兼容客户端通常填写 `https://www.gkotta.bid/v1`；Claude Code 填写根地址。具体路径见相应教程。

## 推荐阅读顺序

1. [快速开始](/docs/quick-start)：注册账户，完成第一次请求。
2. [API 密钥与分组](/docs/api-keys)：查看可用渠道并配置密钥。
3. [客户端接入](/docs/clients)与[使用场景](/docs/scenarios/)：为所用工具选择正确的协议、地址与模型。

## 开始之前

密钥分组决定可用模型、协议与额度。接入前，请在[可用渠道](https://www.gkotta.bid/available-channels)确认权限。本文档首版正文为简体中文，模型、价格与可用性以控制台实时信息为准。
